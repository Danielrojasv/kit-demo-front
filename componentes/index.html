Catálogo de componentes de demo

Panel completo

Dashboard armado: KPIs animados, mapa, feed de eventos, pipeline en vivo y reporte PDF descargable. El punto de partida para la demo.

Pipeline en vivo

Flujo de etapas que se ilumina mientras el backend procesa. Sin dependencias, API de 4 métodos.

Mapa + capa de calor

Leaflet con tiles de OpenStreetMap (sin API key), marcadores con popup y heatmap de intensidad.

Gráficos animados

ECharts: gauge de riesgo, serie suave con área, barras con retardo y radar semanal, en tema oscuro.

Tablero de avance

Kanban de tareas del plan del día: arrastrar entre estados, filtro por persona y atraso marcado en rojo automático. Requiere su servidor (node tablero/servidor.mjs).
